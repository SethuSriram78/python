# Simple Chat Application

## Created By

**Sethu Sriram**

## Project Description

This is a simple Python chat application that allows users to interact
through a text-based conversation system.

## Features

-   User input and response interaction
-   Continuous chat loop
-   Exit option using a keyword
-   Beginner-friendly Python project

## Technologies Used

-   Python

## How to Run

1.  Open terminal or command prompt
2.  Run the Python file:

``` bash
python chat_application.py
```

## Output

The application starts a simple chat interface where users can type
messages and continue chatting until they choose to exit.
